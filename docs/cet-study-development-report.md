# CET 备考大版本开发报告（2026-10-06）

## 范围

本轮把原有首页学习入口扩展为 CET-4/CET-6 备考工作台，并加入听力练习、整卷模拟、学习档案与主观题 AI 学习评分的产品骨架。目标是先在隔离本地环境验收，生产数据、生产数据库和线上路由未改动，也未部署。

## 已实现

- 备考目标：级别、目标分数和考试日期可设置/修改；目标修订不清空历史档案。
- 首页阅读：自动安排经核验状态的文章，逐句阅读、点击词语查看语境义、归档不认识词、文章后阅读题、证据句和错误原因。
- 学习档案：保存阅读、查词、收藏、答题、用时和中断事件，并按账号分页读取。
- 听力练习：按 CET-4/CET-6 结构生成练习；题目、播放、回放、首次答案和最终答案分开记录。
- 整卷模拟：写作 → 听力 → 阅读 → 翻译分阶段推进；阶段计时、刷新/关闭后的继续作答、草稿保存和冲突保护已接入。
- 主观题：复用现有 LLM 池的评分服务，保存作品版本、0–15 学习估分、扣分依据和改写建议；评分失败可重试，不改默写/SRS 统计。
- 记录入口：听力与模考记录以弹窗呈现，继续未完成模拟或查看已完成记录，不新增独立返回路由。
- 原有功能：原词库、错词本、默写、翻译、写作和 AI 入口保留；手机闪卡仅在径向菜单展开且非拖动时按需挂载，菜单收起时卸载。
