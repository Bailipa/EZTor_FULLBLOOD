# 试卷独立发布

## 用户流程与页面职责

管理员入口：后台 → CET内容管理 → 资源目录 → 听力与整卷（`/admin/study`）。

1. 选择 `paper.json`，预览标题、版本、来源和题文。预览不会写数据库。
2. 在“上传听力资源”选择原始MP3/M4A，上传后核对返回URL与JSON引用一致。每文件上限80 MiB，JSON上限1,500,000字节。文件名由内容SHA-256前24位及格式构成，不能按普通原文件名引用。
3. 点“导入待核验”：服务端再次解析题目，检查本地资源存在、登记、大小及哈希，创建不可变版本和资源关联。失败事务回滚，不会留下半套试卷。
4. 查看题文、答案，实际试听，填写审核说明，再“审核并发布”。发布时再次检查资源。已批准原创卷沿用全体登录用户默认可用；真题仍需逐套授权。
5. 学员刷新四六级页面/重新打开试卷目录即可选择，资源权限从数据库实时读取。无需编辑静态index、重新构建或重启服务。

未登录、非管理员、账号切换、被封禁账号不能上传。上传资源本身不会让学员获得访问权；新资源必须关联已发布且该用户可用的试卷。桌面与手机共用现有可换行表单、主题色和返回导航，没有新页面或原生系统选择器。

## 刷新、失败与修订

- 上传或导入中断后可重传同一文件：相同音频校验后复用，相同slug/version且内容一致复用试卷；文件不会覆盖历史资源。
- 上传成功后刷新可能丢失前端成功提示，但服务端文件和登记保留，重新上传即可恢复确认；目前是整文件重试，不支持断点续传。
- 上传文件与数据库不能组成单一事务。文件落盘后若登记失败会保留未关联的内容文件，以便重试；它不对学员开放。进程异常退出可能遗留`.upload-*`，需运维确认无上传任务后清理；不自动删除共享文件。
- 已有版本正文不允许覆盖：修订应增加version后导入、审核。目录显示同slug的最高已批准版本，历史作答仍引用原版本。
- 撤回后新卷和其独有资源停止对学员开放；历史作答不删除。老静态资源目录作为兼容路径保留既有授权行为，未在本次迁移中回填或重写。
- 未做浏览器桌面/手机验收或真实上传/发布端到端验收，不能仅凭静态检查认为上线完成。

## 首次部署准备（以后加卷不再需要这些步骤）

1. 按项目发布规程备份目标数据库并校验；本次没有执行迁移或访问服务器。
2. 发布包含Prisma Client与新增迁移`20261009120000_add_exam_resources`的代码包。应用全部待迁移项，不能只应用这一项或绕过既有迁移门禁。
3. 设置`STUDY_RESOURCE_DIR`为发布目录之外的**绝对共享目录**，包含已有资源，运行用户应能读写；也可以继续使用已有`public/study/resources`外部共享软链接。生产上传入口会拒绝把文件写入当前发布目录内部。多实例必须共享同一目录。本地开发默认使用项目`public/study/resources`。
4. 确认Nginx/CDN上传限制至少80 MiB；例如该后台资源接口对应的Nginx location设置`client_max_body_size 80m;`，转发至现有应用。根据实际线路配置超时。不得用Nginx静态alias绕过`/study/resources/`及`/api/study/resources/`的登录/授权处理。
5. 在目标目录和目标数据库环境执行`node scripts/check-deploy-migrations.cjs`；会检查迁移校验与两张资源表存在。准备包启动入口也执行此门禁。
6. 发布后用管理员上传、导入、审核，再用普通用户检查目录、试听/Range、撤回以及无权限账号访问；核对用户历史作答计数及资源SHA-256。确认真实流程后再记“线上已验收”。

## 数据、兼容与限制

新增`ExamResource`保存文件SHA-256、字节数与格式；`ExamPaperResource`保存文件到不可变试卷版本的关联。上传、导入和审核沿用管理员认证、同源CSRF、账号核对、限流和审计。上传采用有界流式落盘，预留空间、比对文件头/全文件哈希、原子落盘且不覆盖同名内容；播放不重复做全文件哈希。

目前只增加MP3/M4A的独立上传，未增加PDF、图片上传、在线命题编辑或转码服务。文件头检查不是音频完整解码/听感验证，发布前仍需实际试听；JSON时长来自内容包，未新增服务端ffprobe时长核对。已有HTTPS音频及旧`/study/audio/`兼容行为不变；新增卷建议统一使用受权限控制的本地资源URL。

旧JSON目录只用于既有资源兼容和旧导入脚本，不再要求把新卷加进`content/cet-original/index.json`。本次模拟卷02未导入数据库；2.5.0 已部署至体验版，生产站未切换。

## 备份与回滚

数据库备份必须与共享资源快照一起保存。上传文件不放版本发布归档里，切换/清理版本不能删除共享目录。新增迁移仅增表，不修改原卷/作答数据。若回滚旧代码，新资源关联不会被旧代码读取，因此新上传卷的音频不能保证在旧代码正常播放；应先撤回该批新卷再回滚，保留表及共享文件，不删表或伪造回滚数据。
