# CET4/CET6 资源核验研究（查阅于 2026-10-06）

## 官方资料

- [考试大纲页面](https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm)当前列出《全国大学英语四、六级考试大纲（2016年修订版）》。[原始 PDF](https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)。大纲包含四、六级样卷/答题卡，可核对题型与卷面结构；此次浏览确认页面和 PDF URL，但网页工具因 PDF 体积未能完整解析 PDF 全文。
- [CET笔试考核内容](https://cet.neea.edu.cn/html1/report/16123/177-1.htm)确认英语采用多题多卷，并列出四、六级题型和时长。此处是格式基准，不是历年题文/答案授权来源。
- 该官方问答页列明四级笔试总计57题、125分钟，六级笔试总计57题、130分钟，并分别列出写作、听力、阅读和翻译的题型与时间；实现中的试卷 schema/计时校验以此作为结构依据，不把结构页面当作题文许可。
- 本轮检索未发现教育考试院提供可公开下载的历年英语四/六级完整试卷及答案目录。官方大纲中的样卷不能代替历年真题。

## 可用的公开索引（真伪待逐卷交叉核验）

- [WeHUSTER 四级索引](https://www.wehuster.com/cet4)与[六级索引](https://www.wehuster.com/cet6)：页面按年、月份和第1/2/3套列题目及答案链接；本轮打开并核对了四级页，看到2019–2026考次条目。索引存在不等于卷面真实或已获授权。
- [0609x/CET46-Resources GitHub](https://github.com/0609x/CET46-Resources)：README自述汇集2014–2026四级、2013–2026六级，按 `YYYY.MM` 和卷号组织，并包含PDF/Word/答案解析/听力；README同时声明非官方、未获考试机构或培训机构授权，底层材料权利归原权利人。可用于定位/覆盖盘点，不能作为真实性或再分发许可证明。
- [AayuBal/cet-exams GitHub](https://github.com/AayuBal/cet-exams)：README自述含2019–2025真题和答案/音频，可辅助发现条目；本轮未逐份核验文件，不以代码仓库或托管链接授权底层内容。

## 结论边界

已核实：官方大纲页面列出2016修订版；官方考核内容页说明多题多卷；以上公开索引当前可访问且宣称按考次提供资料。未核实：任何具体历年卷的原始来源、完整性、每题文字、标准答案与听力音频是否准确，也未找到官方逐年卷/答案PDF或可供本产品再分发的权利文件。未下载或导入题文。非营利、公开可下载、GitHub仓库许可证或第三方页面均不能单独证明题文可再分发。
