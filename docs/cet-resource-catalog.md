## 年份、级别、卷别逐份核验

以 `级别-YYYY.MM-卷号-材料类型` 建立清单。每一考次、每一卷单独记录（年份+月份不可省略；补考月份独立建档）：

1. **发现与留证**：记录来源页URL、文件直链、访问日期、发布者/书目信息、文件名、格式、页数、文件哈希及取得方式；保存来源页面截图或存档。把第三方目录标记为“待核验”，不可仅凭目录描述打真题标签。
2. **身份交叉核对**：至少用两个彼此独立的来源比对考试级别、年月/补考场次、卷号、题目顺序、作文/翻译题目、听力文本/音频时长及页码。再对照官方大纲的题型与结构。媒体转载相同源稿或镜像不算独立来源。无可信第二来源、来源互相矛盾或无法确认的，标为“未证实/隔离”，不入正式题库。
3. **逐题原文核对**：将PDF逐页与抽取/OCR文本对照，涵盖题干、段落、选项、编号、标点、图表、空格和页序；不因机器可搜索就视为正确。记录核验人、日期、疑点和修订，不覆盖原始文件。
4. **答案独立核对**：答案表必须标清其卷号和题号。将客观题逐项对照两份独立答案来源（优先出版社正式配套答案/有可验证书目信息的出版物；再与独立解析或可信考生回忆稿比对）。按选项内容核对，不能只核 A/B/C/D，因为多卷选项顺序可能不同。答案不一致时回到原题与证据句/听力文本复查，保留分歧并暂停发布。作文、翻译的参考答案应标为范文/参考译文，不宣称唯一标准答案。
5. **权利审核**：逐项确定题文、音频、答案解析和扫描版的权利人及可在本产品内复制、展示、存储、分发的明确依据。没有书面授权/明确适用许可时，仅保留来源元数据与核验记录，不导入正文、音频或答案。免费、非营利、公开下载、第三方收录、GitHub代码许可证都不能代替底层材料授权。

建议状态：`DISCOVERED → IDENTITY_CHECKED → TEXT_CHECKED → ANSWER_CHECKED → RIGHTS_CLEARED → PUBLISHED`。真实性和权利是两项独立门槛；任何一项不通过即不发布。状态变化须附可复核证据与责任人。

## OCR及答案错误检测

- 先看每页渲染图，再抽取文本；按页对照并标记 OCR 低置信区域。重点排查 `I/l/1`、`O/0`、单复数、否定词、连字符、引号、数字/年份、题号、A–D选项顺序、跨栏串行、表格/匹配题错位和页眉页脚混入。
- 检查结构约束：页数和题号连续性；官方结构所列题型/题数/时长是否匹配；四选一题是否都有四个选项；段落、选项、题号是否重复或缺失。结构吻合只能发现异常，不能证明来源真实性。
- 机器抽取/OCR文本与独立人工复核稿做逐页差异比对；对题干、选项、答案键及影响作答的标点实行双人复核。修正记录保留原 OCR、修订值、页码及理由。
- 答案键校验检查题号集合、重复/漏题、卷别错配、答案字母与实际选项内容的映射；独立复核争议题的原文证据，听力题还须回听音频并对照逐字稿。解析结论与答案冲突时隔离该题，不自动选多数答案。
- 每个文件计算哈希并固定版本；替换文件时重新跑全套核验。正式上架后抽样复核不能替代首次逐题核验。
