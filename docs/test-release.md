## 隔离与资源

- 使用独立发布目录、进程、端口及测试数据库，域名反向代理到测试进程；不复用生产数据库。数据库连接及认证回跳地址由服务器环境配置，环境文件不上传 Git。
- Git 保存代码、迁移、小型题目 JSON 和来源/校验清单；音频、写作图表按需独立交付。PDF、原压缩包及本地数据库不上传，可靠源 PDF 仅保留在本地供转换与核对。
- 仅使用 `content/cet-local` 的 86 套试卷。运行资源白名单为 `index.json` 中 `category=audio` 的 50 个音频及 `writing-figures.json` 的 3 张图片，共 53 个文件，放置于 `public/study/resources/`，保持现有 URL。来源元数据保留，159 个 PDF 不进入应用包或独立资源包。
- 旧 GitHub 资源、2019 样例及争议候选已移除文件与导入入口；历史本地作答数据未清除。测试环境从当前内容包导入，不复制本地用户和历史作答。
- `scripts/import-cet-library.ts --test-release --import` 只接受localhost的 `eztor_test` 数据库，并要求认证地址为此测试域名；普通模式仍限定本机 `eztor`。采用现有导入/审核服务，不导入旧包。

## 发布与验收

1. 通过 `scripts/bump-version.sh` 同步版本；记录提交、构建号、工作区状态和迁移列表。
2. 核对服务器可用空间，计入资源包、解压目录、数据库迁移空间和回滚版本；创建并校验测试数据库备份。
3. 构建并检查发布包白名单，资源按上述 53 个文件清单独立核对 SHA-256；排除 PDF、环境文件、数据库、ZIP、OCR 缓存和本地预览目录。`DEPLOY_EXTERNAL_STUDY_RESOURCES=1` 时应用包不含学习资源；默认应用包也仅复制清单中的音频与写作图表。
4. 在独立测试数据库执行迁移与当前内容包导入，核对四六级各 43 套、目录 86 套及资源引用。
5. 配置域名与 HTTPS，核对认证回跳、进程和数据库连接；验收登录、练习、换卷、保存/刷新恢复、标记跳转、查词、音频及缺项提示。
6. 记录失败恢复和回滚目标；真实流程验收前不标记“线上已验收”。

## 性能边界

首屏总数接口只查询批准内容的 slug 并合并资源清单，不组装完整目录；完整目录按需读取。接口鉴权及私有、不缓存响应规则保持现有行为。单机读取时间和构建通过不能作为生产并发容量证明。
