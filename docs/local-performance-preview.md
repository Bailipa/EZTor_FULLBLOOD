# 本地流畅度预览

编辑使用 `npm run dev`（3000）；体验检查使用独立的生产构建（3001）。

本地开发默认使用 Turbopack。需要复现 Webpack 的特定问题时，先停止当前开发服务，再运行 `npm run dev:webpack`；不要同时启动两套开发服务，也不要向默认命令追加 `--webpack`（两个打包器标志会冲突）。

```sh
npm run preview:build
npm run preview:start
```

打开 http://127.0.0.1:3001/ai 。代码修改不会自动更新此预览；先在启动预览的终端按 Ctrl+C，再重新构建、启动。3001 被占用时构建会停止，保护正在运行的快照。

源码快照与构建产物位于已忽略的 `.local-preview/`，不修改原 `.next/dev`、tsconfig 或 next-env。脚本复用现有依赖，不复制 `.env`、安装包或数据库；加载本地开发环境，仅允许回环地址的 PostgreSQL。普通部署仍使用原 `npm run build`。

当前预览用于匿名流程对照：现有生产认证要求 Secure Cookie，HTTP 预览不继承开发环境的登录状态；未验证登录、私人词库、AI 请求和安装包下载。预览共享本地开发数据库，应按正常应用使用，不连接生产数据库。

2026-10-05 对照：`/ai` 初始 HTML 引用的脚本解压体积，Webpack 开发版 28,107,717 字节，Turbopack 生产版 1,178,774 字节。这个差异包含构建模式、打包器和源码映射，不能作为业务代码优化比例或真实手机响应指标。
