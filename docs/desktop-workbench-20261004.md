# 桌面工作台调整

## 目标流程

```text
工作台 → 每日单词 / 今日任务 → 默写、查词或设置
翻译与聊天 → 实时翻译 / 中译英 / 译句子 / AI 助手 / 聊天室
默写复习 → 练习与错词本工作区 → 配置 → 默写 → 即时错词记录 / 结果
词库 → 生词本 / 公共词库 / 单词贡献榜 → 同屏查询与管理
词库 → 生词本 / 错词本 / 公共词库 / 单词贡献榜
排行榜 → 学区与学力排名
底部工具区 → 设置 / 主题 / 下载与支持
```

桌面侧栏保留五个主入口。词库子栏目在内容区横向切换；设置与低频工具在侧栏底部。首页直接呈现学习内容，减少大幅欢迎横幅与跳转卡片。页面使用统一紧凑标题、工具栏和内容宽度。

## 范围和验收

- 桌面断点从 768px 开始；1024px 起侧栏展开文字。
- 手机径向导航与原有页面布局保留。
- 检查主导航、词库子栏目、每日单词、任务跳转、设置滚动与翻译聊天的可用空间。
- 验证 1440、1024、768 和 390px 视口，没有横向溢出或标题重复。
- 保留业务数据和既有接口；本次不部署、不修改版本号。

## 翻译页多区布局

```text
宽屏（≥1440px）
实时翻译 │ 中译英 │ AI 助手 / 聊天室
         │ 译句子 │

中等窗口（1100–1439px）
实时翻译 │ 当前选中的辅助功能

窄窗口（<1100px）
顶部栏目 → 当前功能
```

已打开的翻译区保持挂载，缩放或切换栏目时保留查询、句子输入和结果；草稿不新增持久存储，刷新时仍按原有规则处理。对话区选择按账号保存在本地导航记录中。聊天室只在可见时连接，离开后按既有方式恢复消息。各栏独立滚动，手机继续使用原有单区和径向导航。

## 复习页多区布局

≥1100px 同时呈现练习与错词本，进入 /mistakes 时将错词本放在左侧主区；较窄窗口以同页栏目切换，保留正在输入的答案。答错先呈现保存状态，现有逐题接口确认成功后刷新错词记录和次数；请求失败显示未确认同步，不自动重发计数写入。普通练习和错词专练分别保存中断进度。

## 词库多区布局

≥1440px 同屏呈现生词本、公共词库和单词贡献榜；1100–1439px 在选择生词本或公共词库时并列显示这两栏，选择贡献榜时并列显示公共词库与贡献榜；<1100px 同页切换栏目。每个区域独立滚动，保留各自查询、管理、纠错/贡献表单、分享和分页操作。去除桌面重复的词库二级导航，使用工作区中的栏目导航。未修改词库数据接口或记录。
