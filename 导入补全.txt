# 单词库填充需求文档

## 1. 需求背景

当前系统中的单词库（包括“大学英语四六级核心词汇”、“雅思核心词汇”、“考研核心词汇”等）显示为0词，需要从外部数据源填充内容，以提供完整的词汇学习功能。

## 2. 需求目标

1. 从指定的 GitHub 仓库下载单词数据，填充到系统的默认单词库中
2. 调整单词库结构，将“四六级词汇”拆分为单独的“四级词汇”，避免四级和六级词汇混合在一个库中
3. 确保填充后的单词库能够正确显示词数和相关信息

## 3. 数据源分析

### 3.1 数据源信息

- **数据源地址**：https://github.com/KyleBing/english-vocabulary.git
- **数据格式**：包含 txt 和 json 两种格式
- **数据内容**：涵盖初中、高中、四级、六级、考研、托福、SAT 等多个级别的词汇

### 3.2 数据结构

- **txt 版本**：格式为 `单词\t释义`，只包含词条和注释
- **json 版本**：包含词条、多条注释、多条词组及注释
- **单词数量**：
  - 初中：3223词
  - 高中：6008词
  - 四级：7508词
  - 六级：5651词
  - 考研：9602词
  - 托福：13477词
  - SAT：8887词

## 4. 需求详细说明

### 4.1 单词库填充

1. **下载数据**：从 GitHub 仓库下载完整的单词数据
2. **数据转换**：将下载的数据转换为系统可识别的格式
3. **填充逻辑**：
   - 大学英语四级词汇：使用仓库中的四级词汇数据
   - 大学英语六级词汇：使用仓库中的六级词汇数据
   - 考研核心词汇：使用仓库中的考研词汇数据
   - 雅思核心词汇：使用仓库中的托福词汇数据（作为替代）
   - 其他默认词库：根据实际情况选择合适的数据源

### 4.2 单词库结构调整

1. **拆分四六级词汇**：
   - 将现有的“大学英语四六级核心词汇”拆分为“大学英语四级核心词汇”和“大学英语六级核心词汇”
   - 分别填充对应级别的词汇数据
2. **保留其他词库**：保持“雅思核心词汇”、“考研核心词汇”等其他词库的结构不变

### 4.3 数据质量要求

1. **完整性**：确保每个单词库都包含完整的词汇数据
2. **准确性**：确保单词和释义的对应关系正确
3. **一致性**：确保不同词库的数据格式一致
4. **实时性**：确保显示的词数与实际填充的词汇数量一致

## 5. 实施步骤

1. **数据准备**：
   - 克隆 GitHub 仓库到本地
   - 提取各个级别的词汇数据
   - 转换数据格式为系统所需格式

2. **数据填充**：
   - 为每个默认词库创建对应的数据库记录
   - 将转换后的数据填充到数据库中
   - 更新词库的词数字段

3. **验证测试**：
   - 检查词库显示的词数是否正确
   - 测试单词导入功能是否正常
   - 验证单词库的显示和使用是否正常

## 6. 预期结果

1. 所有默认词库都显示正确的词数
2. “大学英语四级核心词汇”和“大学英语六级核心词汇”分别显示对应的词汇数据
3. 单词导入功能能够正常工作，用户可以导入这些词库
4. 系统能够正确显示和管理填充后的单词库

## 7. 风险评估

1. **数据格式转换风险**：GitHub 仓库的数据格式可能与系统所需格式不完全匹配，需要进行适当的转换
2. **数据量风险**：部分词库（如托福）词汇数量较大，可能需要分批处理
3. **系统性能风险**：填充大量词汇数据可能对系统性能造成暂时影响

## 8. 交付标准

1. 所有默认词库都填充了相应的词汇数据
2. 词库显示的词数与实际填充的词汇数量一致
3. “四六级词汇”已拆分为“四级词汇”和“六级词汇”
4. 单词导入功能能够正常使用这些词库
5. 系统运行稳定，无异常错误
6. 确保词库操作的流畅性
