一、项目背景
================================================================================

1.1 现有系统概述
当前项目是一个基于 Next.js + Prisma + SQLite 的英语词汇学习系统，主要功能包括：
- 单词翻译与解析（调用 LLM API）
- 用户个人词库管理（Word 模型）
- 全局公共词库（PublicWord 模型）
- 复习分组功能（ReviewGroup 模型）
- 闪卡默写功能
- 用户认证系统（NextAuth）

1.2 现有数据库模型（prisma/schema.prisma）
核心模型：
- User：用户信息
- Word：用户个人单词（与 User 一对多）
- PublicWord：全局公共词库（管理员维护）
- ReviewGroup：用户复习分组
- ReviewGroupWord：分组与单词的关联表（多对多）
- IgnoredWord：用户忽略的单词

1.3 外部词汇库资源
GitHub 仓库：https://github.com/KyleBing/english-vocabulary.git
包含内容：
- 四六级词汇
- 考研词汇
- 雅思词汇
- 其他英语考试词汇

================================================================================
二、功能概述
================================================================================

实现词库导入与分享功能，允许用户通过密钥机制在不同用户间分享词库分组，
同时提供默认词库密钥，确保功能实现不影响现有项目架构，并与当前分组架构
保持一致。

核心特性：
1. 基于 ReviewGroup 分组的分享机制
2. 唯一密钥码生成与验证
3. 默认词库密钥（四六级、雅思、考研）
4. 数据归属清晰，导入后数据与原分享者隔离
5. 与现有分组架构完全兼容

3.2 密钥导入功能
--------------------------------------------------------------------------------

3.2.1 密钥验证
API: GET /api/share/validate/:code
验证内容：
- 密钥格式是否正确
- 密钥是否存在
- 是否已过期（expiresAt）
- 是否达到使用上限（maxUses vs usedCount）
- 当前用户是否已导入过（防重复）

返回数据：
{
  valid: boolean,
  data?: {
    code: string,
    name: string,
    description: string | null,
    wordCount: number,
    shareType: string,
    expiresAt: DateTime | null,
    maxUses: number | null,
    usedCount: number,
    creator: string
  },
  error?: string
}

3.2.2 数据拉取
API: GET /api/share/data/:code
拉取分享内容数据：
- 根据 shareType 获取对应单词列表
- 如果是 ReviewGroup 分享，通过 ReviewGroupWord 关联表获取
- 返回单词完整信息（word, phonetic, pos, translation, example 等）

3.2.3 导入逻辑
API: POST /api/share/import
请求参数：
{
  code: string,           // 分享密钥
  customName: string,     // 用户自定义的词库名称
  targetGroupId?: string, // 目标分组 ID（可选，不传则创建新分组）
  createNewGroup?: boolean, // 是否创建新分组（默认 true）
  skipExisting?: boolean  // 是否跳过已存在的单词（默认 true）
}

导入流程：
1. 验证密钥有效性
2. 检查用户是否已导入过（SharedVocabularyImport 表）
3. 获取分享的单词列表
4. 处理分组逻辑：
   - 如果 targetGroupId 存在且有效，使用该分组
   - 如果 createNewGroup 为 true，创建新分组（名称为 customName）
   - 如果选择现有分组，添加到该分组
5. 批量导入单词到 Word 表：
   - 使用 upsert 避免重复
   - 关联到当前用户 ID
   - 保留原始数据（phonetic, pos, translation 等）
6. 如果是分组导入，创建 ReviewGroupWord 关联
7. 更新 SharedVocabulary 的 usedCount
8. 创建 SharedVocabularyImport 记录
9. 返回导入统计信息

返回数据：
{
  success: true,
  data: {
    wordsImported: number,   // 成功导入的单词数
    wordsSkipped: number,    // 跳过的单词数（已存在）
    groupId: string,         // 目标分组 ID
    groupName: string,       // 目标分组名称
    shareName: string        // 分享的词库名称
  }
}

3.2.4 错误处理
错误类型与处理：
- INVALID_CODE: 密钥无效 -> 提示"密钥无效，请检查"
- EXPIRED_CODE: 密钥已过期 -> 提示"该密钥已过期"
- MAX_USES_REACHED: 已达使用上限 -> 提示"该密钥使用次数已达上限"
- ALREADY_IMPORTED: 已导入过 -> 提示"您已导入过该词库"
- DATABASE_ERROR: 数据库错误 -> 提示"导入失败，请重试"
- UNAUTHORIZED: 未登录 -> 提示"请先登录"

3.3.3 密钥生成 API
API: POST /api/share/create
请求参数：
{
  reviewGroupId: string,    // 必填，分享的分组 ID
  name: string,             // 分享名称
  description?: string,     // 分享描述
  expiresAt?: string,       // ISO 8601 格式，过期时间
  maxUses?: number          // 最大使用次数，null 表示不限
}

返回数据：
{
  success: true,
  data: {
    code: string,           // 生成的密钥
    name: string,
    description: string | null,
    expiresAt: DateTime | null,
    maxUses: number | null,
    shareUrl: string        // 分享链接（可选）
  }
}

3.3.4 密钥生成算法
要求：
- 唯一性：全局唯一，使用 cuid() 或 uuid 作为基础
- 安全性：难以暴力破解（至少 8 位，包含大小写字母和数字）
- 可读性：去除易混淆字符（如 0/O, 1/I/l）
- 可分段：建议格式 ABC-123-XYZ（便于阅读和输入）

实现示例：
```typescript
function generateShareCode(): string {
  const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';
  const segment1 = Array(3).fill(0).map(() => 
    chars.charAt(Math.floor(Math.random() * chars.length))
  ).join('');
  const segment2 = Array(3).fill(0).map(() => 
    chars.charAt(Math.floor(Math.random() * chars.length))
  ).join('');
  const segment3 = Array(3).fill(0).map(() => 
    chars.charAt(Math.floor(Math.random() * chars.length))
  ).join('');
  return `${segment1}-${segment2}-${segment3}`; // 格式：ABC-123-XYZ
}
```

4.1 新增数据模型

4.1.1 SharedVocabulary（分享记录表）
model SharedVocabulary {
  id              String   @id @default(cuid())
  code            String   @unique // 分享码，如 "ABC-123-XYZ"
  name            String   // 分享名称
  description     String?  // 分享描述
  
  userId          String   // 分享者 ID
  user            User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  // 分享内容类型（仅支持 REVIEW_GROUP）
  shareType       String   @default("REVIEW_GROUP") // 固定为 REVIEW_GROUP
  reviewGroupId   String   // 分享的分组 ID
  reviewGroup     ReviewGroup @relation(fields: [reviewGroupId], references: [id], onDelete: Cascade)
  
  // 分享配置
  maxUses         Int?     // 最大使用次数，null 表示不限
  usedCount       Int      @default(0) // 已使用次数
  expiresAt       DateTime? // 过期时间，null 表示不过期
  isActive        Boolean  @default(true) // 是否激活（可被撤销）
  
  // 统计信息
  importedCount   Int      @default(0) // 成功导入次数（不同用户）
  viewCount       Int      @default(0) // 查看次数
  
  // 元数据
  wordCount       Int      // 分享时的单词数量（快照）
  version         Int      @default(1) // 版本号（重新生成时递增）
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  deletedAt       DateTime? // 软删除标记
  
  @@index([code])
  @@index([userId])
  @@index([reviewGroupId])
  @@index([expiresAt])
  @@index([isActive])
}

4.1.2 SharedVocabularyImport（导入记录表）
model SharedVocabularyImport {
  id              String   @id @default(cuid())
  sharedId        String   // 分享的 ID
  shared          SharedVocabulary @relation(fields: [sharedId], references: [id], onDelete: Cascade)
  
  importerId      String   // 导入者 ID
  importer        User     @relation(fields: [importerId], references: [id], onDelete: Cascade)
  
  // 导入详情
  wordsImported   Int      // 导入的单词数
  wordsSkipped    Int      @default(0) // 跳过的单词数
  targetGroupId   String   // 导入到的分组 ID
  
  // 导入配置快照
  skipExisting    Boolean  @default(true) // 是否跳过了已存在的单词
  
  createdAt       DateTime @default(now())
  
  @@unique([sharedId, importerId]) // 同一用户只能导入同一分享一次
  @@index([importerId])
  @@index([sharedId])
}

4.1.3 DefaultVocabulary（默认词库配置表，可选）
model DefaultVocabulary {
  id          String   @id @default(cuid())
  name        String
  code        String   @unique

  wordCount   Int
  isActive    Boolean  @default(true)
  sortOrder   Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  
  @@index([isActive])
}

七、交互流程详解
================================================================================

7.1 导入流程
--------------------------------------------------------------------------------

步骤 1: 用户点击"密钥导入与分享"按钮
  → 触发 ShareImportModal 打开

步骤 2: 模态框初始化
  → 加载默认词库列表（GET /api/share/defaults）
  → 加载用户现有分组（复用现有 API）

步骤 3: 用户输入密钥或选择默认词库
  → 实时验证密钥格式
  → 如果选择默认词库，自动填充密钥

步骤 4: 系统自动验证密钥（防抖，延迟 500ms）
  → 调用 GET /api/share/validate/:code
  → 显示验证结果（有效/无效及原因）

步骤 5: 用户输入词库名称
  → 默认值：分享名称（可编辑）
  → 验证：非空

步骤 6: 用户选择目标分组
  → 选项：创建新分组 / 选择现有分组
  → 如果选择现有分组，显示分组名称

步骤 7: 用户点击"导入词库"
  → 禁用按钮，显示加载状态
  → 调用 POST /api/share/import

步骤 8: 后端处理导入
  8.1 验证密钥有效性
  8.2 检查是否已导入
  8.3 获取分享数据
  8.4 创建/选择分组
  8.5 批量导入单词
  8.6 创建关联记录
  8.7 更新统计

步骤 9: 显示导入结果
  → 成功：显示"导入成功！共导入 X 个单词，跳过 Y 个"
  → 失败：显示具体错误信息

步骤 10: 关闭模态框，刷新界面
  → 关闭 ShareImportModal
  → 触发父组件刷新分组列表

7.2 分享流程
--------------------------------------------------------------------------------

步骤 1: 用户进入分组管理界面
  → 查看自己的 ReviewGroup 列表

步骤 2: 用户点击某个分组的"分享"按钮
  → 打开 GroupShareModal
  → 加载分组信息（名称、单词数）

步骤 3: 用户配置分享参数
  → 输入分享名称（默认：分组名 + "的词库"）
  → 输入描述（可选）
  → 选择有效期（永不过期/7 天/30 天/自定义）
  → 设置使用次数限制（可选）

步骤 4: 用户点击"生成分享密钥"
  → 调用 POST /api/share/create
  → 显示加载状态

步骤 5: 显示生成的密钥
  → 大字体展示密钥（如：ABC-123-XYZ）
  → 显示有效期和使用限制
  → 提供复制按钮

步骤 6: 用户复制密钥
  → 点击"复制"按钮
  → 复制到剪贴板
  → 显示"复制成功"提示

步骤 7: 用户分享密钥
  → 通过聊天工具、邮件等方式分享给他人

步骤 8（可选）: 管理已生成的密钥
  → 查看统计（查看次数、导入记录）
  → 撤销密钥（使密钥失效）
  → 重新生成密钥（旧密钥失效）

================================================================================
八、安全性设计
================================================================================

8.1 密钥安全
- 密钥长度：至少 8 位，推荐 11 位（分段格式：ABC-123-XYZ）
- 字符集：大写字母 + 数字（去除易混淆字符）
- 熵值：足够抵抗暴力破解（62^11 种组合）
- 验证频率限制：每 IP 每分钟最多验证 10 次

8.2 访问控制
- 所有分享相关 API 均需登录认证
- 用户只能访问自己创建的分享
- 管理员可查看所有分享
- 数据隔离：导入后数据归属当前用户

8.3 防滥用机制
- 分享创建限制：每用户每日最多创建 10 个分享
- 导入频率限制：每用户每小时最多导入 20 次
- 密钥验证限流：防止暴力破解
- 异常行为监控：短时间大量导入触发告警

8.4 数据验证
- 输入验证：密钥格式、词库名称长度等
- 权限验证：分享者权限、分组所有权
- 数据完整性：导入前验证单词数据格式
- 防重复导入：同一用户对同一分享只能导入一次

8.5 审计日志
记录以下操作到 AuditLog 表：
- 创建分享
- 导入词库
- 撤销分享
- 重新生成密钥

================================================================================
九、性能优化
================================================================================

9.1 数据库优化
- 为 code、userId、reviewGroupId 等字段添加索引
- 使用软删除而非硬删除（保留数据可追溯）
- 定期清理过期分享（定时任务）

9.2 API 响应优化
- 分享预览数据缓存（Redis 或内存缓存）
- 分组列表缓存
- 默认词库列表静态化

9.3 批量操作优化
- 分批导入：每批 100 条，避免超时
- 使用事务保证原子性
- SQLite 优化：PRAGMA synchronous = OFF（导入时）

9.4 前端优化
- 密钥验证防抖（500ms 延迟）
- 虚拟列表：大量分组时使用
- 加载状态反馈
- 错误边界处理

10.1 错误类型定义

enum ShareErrorCode {
  INVALID_CODE = 'INVALID_CODE',           // 密钥无效
  EXPIRED_CODE = 'EXPIRED_CODE',           // 密钥已过期
  MAX_USES_REACHED = 'MAX_USES_REACHED',   // 已达使用上限
  ALREADY_IMPORTED = 'ALREADY_IMPORTED',   // 已导入过
  GROUP_NOT_FOUND = 'GROUP_NOT_FOUND',     // 分组不存在
  UNAUTHORIZED = 'UNAUTHORIZED',           // 未授权访问
  DATABASE_ERROR = 'DATABASE_ERROR',       // 数据库错误
  RATE_LIMIT_EXCEEDED = 'RATE_LIMIT_EXCEEDED' // 操作过于频繁
}

- INVALID_CODE → "密钥无效，请检查后重试"

- MAX_USES_REACHED → "该密钥使用次数已达上限"
- ALREADY_IMPORTED → "您已导入过该词库，无需重复导入"
- GROUP_NOT_FOUND → "选择的分组不存在"
- UNAUTHORIZED → "请先登录后再使用此功能"
- DATABASE_ERROR → "导入失败，请稍后重试"
- RATE_LIMIT_EXCEEDED → "操作过于频繁，请稍后再试"

10.3 成功提示
- 导入成功："导入成功！共导入 X 个单词到分组『Y』"
- 分享创建："分享密钥生成成功！已复制到剪贴板"
- 分享撤销："分享已撤销，密钥已失效"

十二、风险与挑战
================================================================================

12.1 技术风险
- SQLite 并发写入性能瓶颈
  解决方案：使用事务、分批处理、优化 PRAGMA 配置
  
- 大批量导入超时
  解决方案：异步处理、进度回调、增加超时时间
  
- 密钥碰撞概率
  解决方案：增加密钥长度、使用 cuid 作为基础

12.2 业务风险
- 用户分享低质量内容
  解决方案：举报机制、管理员审核、质量评分
  
- 版权风险（GitHub 词汇库的开源协议）
  解决方案：确认开源协议、注明来源、合规使用
  
- 服务器负载增加
  解决方案：限流、缓存、异步处理

12.3 安全挑战
- 密钥泄露
  解决方案：设置过期时间、使用次数限制
  
- 恶意批量导入
  解决方案：频率限制、行为监控、审计日志
  
- 数据篡改
  解决方案：权限验证、数据完整性校验
